Цель проекта: провести исследовательский анализ данных сервиса Яндекс Афиша, выявить причины изменения спроса на мероприятия по сезонам, с акцентом на анализ изменений активности осенью по сравнению с летом.

Основные задачи проекта: 
  * предобработка данных;
  * анализ распределения заказов по сегментам и их сезонные изменения;
  * анализ осенней активности клиентов; * выявление популярных партнёров и сегментов;
  * проверка гипотез о повышенной активности пользователей мобильных устройств.

В ходе анализа были сделаны выводы о том, что большинство заказов совершается через мобильные устройства, а также выявлены сезонные тенденции в спросе на различные категории мероприятий. Проведённый статистический анализ подтвердил некоторые предположения о поведении пользователей.

Проект включает рекомендации по улучшению мобильного приложения и планированию сезонных маркетинговых кампаний, что может быть полезно для развития сервиса и увеличения спроса на мероприятия.
